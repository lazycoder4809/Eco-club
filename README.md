💚 Eco Club — Web Platform for Sustainability

Eco Club — это веб-платформа, созданная для людей, которым не всё равно. Здесь пользователи могут регистрироваться, входить в аккаунт и взаимодействовать с идеями устойчивого развития. Проект объединяет современный технологический стек с дизайн-подходом “зелёного будущего”.

🌱 Функционал

регистрация и авторизация пользователей

защищённый доступ к приватным страницам

динамичные eco-анимации и UI-эффекты

clean и минималистичный интерфейс

🛠️ Технологический стек

Frontend:

HTML5

CSS3 (анимации + responsive layout)

JavaScript (Vanilla)

Backend:

Node.js

Express.js

Database:

MongoDB + Mongoose

Auth & Security:

JWT (JSON Web Tokens)

bcrypt (password hashing)

cookies-based session flow

♻️ Дизайн & Концепт

Проект вдохновлён идеей, что цифровой мир тоже может быть экологичным. UI выполнен в свежей, “растительной” палитре, а переходы и анимации — плавные и органичные.
